# FE-P1-IA-UI-001: 前端信息架构重组与 UI 视觉优化方案

## 目标
将前端从"协议调试工具"转型为"动力环境监控平台" — 纯规划文档。

## 核心变更
- 6 模块菜单: 监控中心 | 资产点位 | 三方授权 | 协议诊断 | 系统审计 | 系统设置
- 28 路由重映射, 9 个协议页下沉到诊断模块
- 15 个复用组件 (5 已有 + 10 新增)
- UI 视觉: 深蓝主色 + 状态色 + 监控驾驶舱首页

## 开发顺序
P1A: IA-002 (菜单路由) → UI-001 (组件) → DASHBOARD-001 (首页) → SITE-001 (站点)
P1B: REALTIME/ALARM/MAPPING/TENANT/AUDIT/PROTOCOL

## 安全边界
纯规划, 未修改代码。不访问 FSU, 不执行 SET, 不启 Scheduler。
