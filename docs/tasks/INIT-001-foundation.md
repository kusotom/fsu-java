# INIT-001：机房动环监控平台基础工程初始化

## 任务描述

创建"机房动环监控"平台基础工程，包括：

1. 项目顶层目录结构
2. Java Spring Boot 后端基础工程
3. Vue 3 前端基础工程
4. PostgreSQL docker-compose
5. B接口优先的后端模块骨架
6. B接口相关前端菜单与占位页面
7. 基础文档目录与README
8. 健康检查接口
9. 统一响应与异常处理
10. SOAP/XML/WSDL/FTP 目录结构

## 协议定位

本项目第一阶段以《中国铁塔动环监控系统统一互联 B 接口技术规范（试行）V1.0，2016 年 9 月》为核心协议方向。
