# B接口2016协议概述

## 协议基础

本项目协议基础为《中国铁塔动环监控系统统一互联 B 接口技术规范（试行）V1.0，2016 年 9 月》。

## 核心特征

1. 数据流接口基于 **WebService + SOAP + XML**
2. B 接口包含 **FTP** 文件/图片能力
3. SC 轮询 FSU 获取慢数据时：SC 是客户端，FSU 是服务端
4. FSU 主动上报告警、状态切换等快数据时：FSU 是客户端，SC 是服务端

## 平台角色

平台需要同时预留：
- **SCService** 服务端：接收 FSU 主动上报
- **FSUService** 客户端：主动调用 FSU 获取数据

## 报文基本结构

- Request
- Response
- PK_Type
- Info
- xmlData
