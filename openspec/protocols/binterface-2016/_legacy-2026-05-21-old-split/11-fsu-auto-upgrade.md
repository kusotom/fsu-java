# 11 — FSU 自动升级能力

## 1. 协议定位

B接口2016 协议原文可能包含 FSU 固件远程升级能力（通过 FTP 分发固件包）。

## 2. 协议原文状态

协议手册 §6 中未找到独立自动升级命令。相关能力可能由 SET_FTP + 厂商私有命令实现。

当前项目内 B接口2016 协议手册（`docs/protocol/b-interface-2016-handbook.md`）未包含自动升级章节。

## 3. 当前项目实现

| 能力 | 状态 |
|------|------|
| 自动升级 | ❌ 未实现 |
| 相关命令 | 无 |
| 相关协议依据 | 协议原文不明确 |

## 4. 建议

- 自动升级能力不是当前 P0/P1 优先事项
- 如需实现，需先确认协议原文是否有相关命令定义
- 可能与 FTP 接口联动（通过 SET_FTP 配置固件服务器地址）
