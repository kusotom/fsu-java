## 快慢数据通道说明

快慢数据类别以 `matrices/fast-slow-data-matrix.md` 为准：`GET_DATA`、`GET_HISDATA`、`GET_THRESHOLD`、`GET_LOGININFO`、`GET_FTP`、`GET_FSUINFO` 等 SC -> FSU 查询命令归属慢通道；`SEND_ALARM` 等 FSU -> SC 主动事件上报归属快通道；`LOGIN/LOGOUT` 为注册 / 会话命令，不按测点数据分类。
